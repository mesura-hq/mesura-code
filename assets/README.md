# Brand icons

The detailed Mesura Code source family is the source of truth for full-color application icons:

- `assets/mesura-code/production-master.png`
- `assets/mesura-code/development-master.png`
- `assets/mesura-code/nightly-master.png`

The three channels share one cube. Production carries it plain; development and nightly add an uppercase wordmark — `DEV` and `NIGHTLY` — in the strip below the cube, set in Adwaita Sans at 62px with 17px of extra letter spacing. Every row above y=1097 stays byte-identical to the production master, which is what `scripts/lib/brand-icon-source.test.ts` asserts. Channel identity used to be a coloured frame around the cube instead; the wordmark replaced it because the frame dominated the boot splash and clashed with the metallic palette. A wordmark is unreadable below roughly 64px, so the 16px and 32px favicons no longer distinguish the channels.

The boot splash does not use an application icon. It uses `assets/mesura-code/splash-mark.png`: the same cube cut out of the production master along its hexagonal silhouette, on a transparent 1024x1024 canvas, with no field and no rounded container. A launcher icon carries a container the splash has no use for, and its opaque field cuts a visible square out of the splash background — dark on a dark theme, and much worse on a light one. The mark is channel-neutral; `apps/web/index.html` names the stage in text beside it.

The Linux desktop uses `assets/mesura-code/desktop-master.png`. It preserves the metallic cube on a `#252527` graphite field and uses the standard rounded desktop silhouette selected in the visual review.

The one-color system template is `assets/mesura-code/monochrome.svg`. Full-color surfaces use the detailed raster masters.

The three Icon Composer projects are native Apple inputs. Each project references its channel's detailed Mesura Code raster:

- `assets/dev/app-icon.icon`
- `assets/nightly/app-icon.icon`
- `assets/prod/app-icon.icon`

## Cross-platform exports

On Arch Linux and other supported systems, run `vp run icons:export` from the repository root. The command regenerates the tracked macOS and iOS icon, Linux, Windows, web, and boot-splash assets. It also copies the development web exports to `apps/web/public`.

Run `vp run icons:check` to compare every generated asset with its source without writing files. `scripts/export-brand-icons.test.ts` owns the expected count, so it is not repeated here. The export uses the Sharp and libvips versions pinned in the lockfile, so generated bytes do not depend on the workstation's libvips package.

## macOS exports

Icon Composer's command-line exporter does not expose the `macOS pre-Tahoe` preset. A plain command-line `macOS` export is full bleed and is not suitable for the desktop app, so the export script intentionally leaves the tracked macOS PNGs unchanged and prints a reminder after every run.

The three tracked macOS PNGs remain stale until this native handoff runs on a Mac with Icon Composer 2 or newer.

After changing an Icon Composer project, open it in Icon Composer and export the macOS PNG with exactly these settings:

- Platform: `macOS pre-Tahoe`
- Appearance: `Default`
- Size: `1024pt`
- Scale: `1×`

Save the three exports to:

- `assets/dev/app-icon.icon` -> `assets/dev/blueprint-macos-1024.png`
- `assets/nightly/app-icon.icon` -> `assets/nightly/nightly-macos-1024.png`
- `assets/prod/app-icon.icon` -> `assets/prod/black-macos-1024.png`

The result must be a 1024×1024 PNG with the classic macOS safe area: the opaque icon body is 824×824, inset 100 pixels on every side, with only the native Icon Composer shadow extending into the surrounding transparent canvas.

To have Codex perform the native exports, paste this prompt into a task opened at the repository root:

```text
Use [@Computer](plugin://computer-use@openai-bundled) and the Icon Composer app to export the three macOS app icons in this repository.

For each project below, use Platform: macOS pre-Tahoe, Appearance: Default, Size: 1024pt, and Scale: 1×, then save the PNG to the exact destination:

- assets/dev/app-icon.icon -> assets/dev/blueprint-macos-1024.png
- assets/nightly/app-icon.icon -> assets/nightly/nightly-macos-1024.png
- assets/prod/app-icon.icon -> assets/prod/black-macos-1024.png

Do not resize, composite, or otherwise post-process the exported PNGs.

Verify every result is 1024×1024 and has the classic macOS safe area: an 824×824 opaque body inset 100px on every side, with only Icon Composer's native shadow extending beyond it.
```

Do not edit the generated PNG or ICO files directly.
