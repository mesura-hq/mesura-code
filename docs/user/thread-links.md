# Open thread links in Mesura Code

In **Settings → Integrations → Browser**, set **Open links in** to
**Mesura Code**. The default is **Your default browser**. Choose that option
again to open links outside the app.

On desktop, click an ordinary HTTP or HTTPS link in the chat or terminal to
open it in the thread's browser tab. The browser maximizes over the thread,
and the sidebar stays available. Each thread reuses its own tab: the next link
replaces the current page. Clicking the same link reloads the page.

To close the tab and return to the thread, use the shortcut configured for
**Right Panel: Close** in **Settings → Keybindings**. Closing the tab also exits
the maximized view. See [Keybindings](./keybindings.md) to change the shortcut.
The next link opens a new tab after you close the previous one.

Hold **Ctrl** or **Command** while clicking to use your default browser for
that link. Phones and devices with a primary touch pointer use the default
browser even when you select **Mesura Code**.

Browser tabs that you open manually stay separate from the tab for thread links.
